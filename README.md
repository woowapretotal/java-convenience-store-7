# 우테코 8기 최종 코딩테스트: 편의점 요구사항 분석 및 정리

## 제시된 요구사항 정리 및 분석

구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템을 구현한다.

- 사용자가 입력한 상품의 가격과 수량을 기반으로 최종 결제 금액을 계산한다.
    - 총구매액은 상품별 가격과 수량을 곱하여 계산하며, 프로모션 및 멤버십 할인 정책을 반영하여 최종 결제 금액을 산출한다.
- 구매 내역과 산출한 금액 정보를 영수증으로 출력한다.
- 영수증 출력 후 추가 구매를 진행할지 또는 종료할지를 선택할 수 있다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - Exception 이 아닌 IllegalArgumentException , IllegalStateException 등과 같은 명확한 유형을 처리한다.

**재고 관리**

- 각 상품의 재고 수량을 고려하여 결제 가능 여부를 확인한다.
- 고객이 상품을 구매할 때마다, 결제된 수량만큼 해당 상품의 재고에서 차감하여 수량을 관리한다.
- 재고를 차감함으로써 시스템은 최신 재고 상태를 유지하며, 다음 고객이 구매할 때 정확한 재고 정보를 제공한다.

**프로모션**

- 오늘 날짜가 프로모션 기간 내에 포함된 경우에만 할인을 적용한다.
- 프로모션은 N개 구매 시 1개 무료 증정(Buy N Get 1 Free)의 형태로 진행된다.
- 1+1 또는 2+1 프로모션이 각각 지정된 상품에 적용되며, 동일 상품에 여러 프로모션이 적용되지 않는다.
- 프로모션 혜택은 프로모션 재고 내에서만 적용할 수 있다.
- 프로모션 기간 중이라면 프로모션 재고를 우선적으로 차감하며, 프로모션 재고가 부족할 경우에는 일반 재고를 사용한다.
- 프로모션 적용이 가능한 상품에 대해 고객이 해당 수량보다 적게 가져온 경우, 필요한 수량을 추가로 가져오면 혜택을 받을 수 있음을 안내한다.
- 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제하게 됨을 안내한다

**멤버십 할인**

- 멤버십 회원은 프로모션 미적용 금액의 30%를 할인받는다.
- 프로모션 적용 후 남은 금액에 대해 멤버십 할인을 적용한다.
- 멤버십 할인의 최대 한도는 8,000원이다.

**영수증 출력**

- 영수증은 고객의 구매 내역과 할인을 요약하여 출력한다.
    - 구매 상품 내역: 구매한 상품명, 수량, 가격
    - 증정 상품 내역: 프로모션에 따라 무료로 제공된 증정 상품의 목록
    - 금액 정보
        - 총구매액: 구매한 상품의 총 수량과 총 금액
        - 행사할인: 프로모션에 의해 할인된 금액
        - 멤버십할인: 멤버십에 의해 추가로 할인된 금액
        - 내실돈: 최종 결제 금액

### 검증

구매

- 사용자가 찾는 상품이 존재하는지 검증해야 한다.
- 사용자가 요청한 만큼의 재고가 존재하는지 검증해야 한다.
    - 프로모션 상품인 경우, 프로모션 재고 >= 프로모션 입력 수량
    - 프모모션 상품이 아닌 경우, 일반 재고 >= 일반 구매 입력 수량

### 기능

- 상품 항목에 대한 계산
    - 프로모션 적용
        - 프로모션 대상인지, 그리고 프로모션 날짜에 포함되는지로 부터 프로모션 상품인지 판단
- 모든 상품 항목에 대한 계산
    - 멤버십 할인 적용 (최대 한도 8000원)
- 상품 재고 차감

### 입력

- 사용자는 상품 이름과 수량을 입력한다.
    - 구매할 상품과 수량을 입력 받는다. 상품명, 수량은 하이픈(-)으로, 개별 상품은 대괄호([])로 묶어 쉼표(,)로 구분한다.
    - 예외 경우: 형식이 올바르지 않은 경우
- 프로모션 적용이 가능하지만 해당 수량만큼 입력하지 않은 경우 **프로모션 적용 유무**를 선택할 수 있다.
    - Y: 증정 받을 수 있는 상품을 추가한다.
    - N: 증정 받을 수 있는 상품을 추가하지 않는다.
    - 예외 경우: Y/N이 아닌 경우
- 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우 **구매 유무**를 선택할 수 있다.
    - Y: 일부 수량에 대해 정가로 결제한다.
    - N: 정가로 결제해야하는 수량만큼 제외한 후 결제를 진행한다.
    - 예외 경우: Y/N이 아닌 경우
- 멤버심 할인 적용 유무를 입력받는다.
    - Y: 멤버십 할인을 적용한다.
    - N: 멤버십 할인을 적용하지 않는다.
    - 예외 경우: Y/N이 아닌 경우
- 추가 구매를 진행할지 또는 종료할지를 선택할 수 있다.
    - Y: 재고가 업데이트된 상품 목록을 확인 후 추가로 구매를 진행한다.
    - N: 구매를 종료한다.
    - 예외 경우: Y/N이 아닌 경우

- 상품 목록과 행사 목록을 파일 입출력을 통해 불러온다.
    - src/main/resources/products.md 과 src/main/resources/promotions.md 파일을 이용한
      다.

### 출력

- 환영 인사와 함께 상품명, 가격, 프로모션 이름, 재고를 안내한다. 만약 재고가 0개라면 `재고 없음` 을 출력한다.
- 프로모션 적용이 가능한 상품에 대해 고객이 해당 수량만큼 가져오지 않았을 경우, 혜택에 대한 안내 메시지를 출력한다.
- 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제할지 여부에 대한 안내 메시지를 출력한다.
- 멤버십 할인 적용 여부를 확인하기 위해 안내 문구를 출력한다
- 구매 내역과 산출한 금액 정보를 영수증으로 출력한다.
- 추가 구매 여부를 확인하기 위해 안내 문구를 출력한다.
- 상품 재고를 업데이트한다
- 사용자가 잘못된 값을 입력했을 때, "[ERROR]"로 시작하는 오류 메시지와 함께 상황에 맞는 안내를 출력한다.

## 도메인 정리

### 상품(엔티티)

- 이름
- 가격
- 재고 (VO)
- 프로모션 상품

### 프로모션(VO)

- 행사이름
- 구매 개수
- 증정 개수
- 시작일
- 종료일
- 기능: 프로모션이 적용되는 시간인지 판별할 수 있다.

### 프로모션 상품(VO)

- 프로모션
- 재고

### 재고(불변 VO)

- 재고는 0 이상이어야 한다.
- 차감 가능하다

### 상품 항목(VO)

- 상품명
- 상품 수량
- 가격

### 주문

- 상품 항목 목록
- 기능: 총 구매액 계산

### 증정

- 상품 항목 목록
- 기능: 행사 할인 계산

### 영수증

- 주문
- 증정
- 멤버십 유무
- 기능: 멤버십 할인 금액 계산
- 기능: 지불 금액 계산

## 유즈케이스 정리

- 상품 목록을 조회한다.
- 상품 구매를 요청한다.

## 비즈니스 로직 정리

- 상품 목록을 조회한다.
    - 저장소에서 상품 목록을 조회한다.
- 상품 구매를 요청한다.
    - 상품의 존재 유무를 파악한다.
    - 주문 영역을 구성한다.
    - 증정 영역을 구성한다.
        - 주문 영역으로 부터 프로모션 정보를 도출한다.
    - 재고를 차감한다.
        - 프로모션 및 상품 재고를 차감한다.
        - 저장소에 최신화한다.
    - 멤버십을 적용한다.
    - 지불 금액을 계산한다.
    - 영수증을 반환한다.

## Layer 구분

### MenuSelectDispatcher(Presentation Layer)

- 사용자가 선택한 메뉴를 처리할 수 있는 Controller를 찾아 처리하도록 합니다.(dispatch)

### Controller(Presentation Layer)

- 사용자 요청을 받아 유즈케이스를 처리하고, 그 결과를 사용자에게 반환합니다.

### ConsoleInputAdapter(Presentation Layer)

- 사용자 입력을 Application이 처리할 수 있는 형태로 변환합니다.
- 입력을 위한 콘솔 프롬프트를 담당합니다.

### Application Service

- Application이 처리하는 유즈케이스를 담당하고, 비즈니스 로직 오케스트레이션 및 트랜잭션 경계를 담당합니다.

### Domain Service

- 도메인 객체 생성 및 도메인 로직 수행을 담당합니다.
- Bounded Context를 넘어가거나 여러 도메인 객체가 협력해야 하는 로직을 담당합니다.
